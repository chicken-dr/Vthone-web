MVP Grammar Reference

Grammar Reference

EBNF-like grammar definition for the Vthon MVP language.

Overview

This document defines the Vthon MVP grammar using EBNF-like notation. The grammar describes the concrete syntax that the parser accepts.

Conventions

  • NAME - Non-terminal (rule name)
  • "literal" - Terminal (exact keyword/symbol)
  • [optional] - Optional element
  • {repetition} - Zero or more repetitions
  • A | B - Alternative (A or B)
  • (group) - Grouping

Expression Placeholder

EXPR represents a Python-compatible expression. Vthon does not parse expression structure in the MVP; expressions are treated as source fragments and validated by the transpiler using Python's ast.parse(). Vthon literals true, false, null are also accepted in expressions.

EBNF Grammar

grammar.vth
program       = { statement | NEWLINE } EOF ;

statement     = simple_stmt | compound_stmt ;

simple_stmt   = let_decl | const_decl | assignment | return_stmt
              | import_stmt | raise_stmt | break_stmt | continue_stmt | expr_stmt ;

let_decl      = "let" NAME [":" EXPR] "=" EXPR ;

const_decl    = "const" NAME [":" EXPR] "=" EXPR ;

assignment    = EXPR ASSIGN_OP EXPR ;

return_stmt   = "return" [EXPR] ;

import_stmt   = ["py"] "import" EXPR | ["py"] "from" EXPR "import" EXPR ;

raise_stmt    = "raise" [EXPR] ;

break_stmt    = "break" ;

continue_stmt = "continue" ;

expr_stmt     = EXPR ;

compound_stmt = function | class | if_stmt | while_stmt | for_stmt | try_stmt ;

function      = "fn" NAME "(" [parameters] ")" ["->" EXPR] ":" suite ;

class         = "class" NAME ["(" EXPR ")"] ":" suite ;

if_stmt       = "if" EXPR ":" suite {"elif" EXPR ":" suite} ["else:" suite] ;

while_stmt    = "while" EXPR ":" suite ;

for_stmt      = "for" EXPR "in" EXPR ":" suite ;

try_stmt      = "try:" suite {"catch" [EXPR ["as" NAME]] ":" suite}
                ["finally:" suite] ;

suite         = NEWLINE INDENT {statement | NEWLINE} DEDENT ;

parameters    = {parameter} ["," parameter] ["," ["*"] NAME] ["," ["**"] NAME] ;
parameter     = NAME [":" EXPR] ["=" EXPR] ;

Terminal Symbols

SymbolDescription
NAMEIdentifier: [A-Za-z_]\w*
EXPRPython-compatible expression fragment
ASSIGN_OPAssignment operator: = += -= *= /= //= %=
NEWLINELine terminator (logical line)
INDENTIndentation increase (4-space multiple)
DEDENTIndentation decrease
EOFEnd of file

Token Definitions

Keywords (Reserved)

let const fn class if elif else while for try catch finally
return raise break continue pass import from as py true false null

Operators

All Python 3.10+ operators are accepted in expressions. The parser treats them as part of EXPR fragments.

Delimiters

Parentheses (), brackets [], braces {}, comma ,, colon :, dot ., arrow ->.

Indentation Tokens

The lexer produces logical INDENT/DEDENT tokens based on 4-space indentation levels. Tabs are rejected.

Operator Precedence (Expressions)

Since expressions are parsed as Python-compatible fragments, operator precedence follows Python 3.10+ rules. This table is for reference.

Notes

  • The grammar is intentionally minimal for MVP. Expressions are delegated to Python's parser.
  • suite requires at least one statement (empty blocks need pass)
  • try requires at least one catch or finally
  • fn init inside a class is lowered to __init__
  • Method parameters without self/cls receive implicit self
