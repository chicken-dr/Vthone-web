Language Specification

Formal definition of the Vthon language syntax, semantics, and execution model.

1. Source and Layout

File Format

  • Encoding: UTF-8
  • Extension: .vth
  • Line endings: LF (Unix) or CRLF (Windows)

Indentation

Blocks are defined by indentation using spaces only:

  • Indentation must be a multiple of 4 spaces
  • Tabs are not allowed for indentation (compile-time error)
  • Inconsistent indentation within a block is an error
Valid
fn example():
    let x = 1
    if x > 0:
        print(x)
    else:
        print(-x)
Invalid (tabs)
fn example():
	let x = 1  # ERROR: tabs not allowed

Comments

Comments start with # and extend to end of line. They are ignored outside of string literals.

# This is a comment
let x = 1  # Inline comment
let s = "hello # not a comment"

2. Lexical Literals

Numbers

All Python 3.10+ numeric forms are supported:

TypeExamples
Decimal42, 3.14, 1e10
Binary0b1010, 0B1101
Octal0o52, 0O77
Hexadecimal0x2a, 0XFF
Underscores1_000_000, 0xFF_FF

Strings

Single-quoted, double-quoted, and triple-quoted strings with escape sequences:

let single = 'hello'
let double = "world"
let multi = """line 1
line 2"""
let escaped = "tab:\t newline:\n quote:\""

Booleans

Keywords true and false (lowercase) transpile to Python True and False.

Null

Keyword null transpiles to Python None.

Collections

List and dictionary displays use Python syntax:

let list = [1, 2, 3]
let dict = {"name": "Ada", "age": 36}
let nested = [{"x": 1}, {"x": 2}]

Expressions

Expressions use Python-compatible operators (arithmetic, comparison, logical, bitwise, subscript, attribute access, calls). Vthon keywords true, false, null are accepted in expressions and converted during transpilation.

3. Bindings

Variables (let)

Mutable bindings created with let:

let x = 10
let name = "Vthon"
let items = [1, 2, 3]
x = 20  # Reassignment allowed

Optional type annotation (not enforced at runtime in MVP):

let x: int = 10
let name: str = "Vthon"
let items: list = [1, 2, 3]

Constants (const)

Compile-time protected bindings created with const:

const PI = 3.14159
const MAX_SIZE = 100
const DEFAULT_NAME = "unknown"

Reassignment to a const is a compile-time error:

const PI = 3.14159
PI = 3.14  # ERROR: cannot assign to constant 'PI'
Note: Constants are not a security boundary. Mutation through aliases or Python reflection is possible. The protection is compile-time only within the same compilation unit.

4. Control Flow

Conditional (if/elif/else)

if x > 0:
    print("positive")
elif x < 0:
    print("negative")
else:
    print("zero")

While Loop

let n = 5
while n > 0:
    print(n)
    n -= 1

For Loop

for i in range(5):
    print(i)

for name in ["Ada", "Alan", "Grace"]:
    print(name)

Loop Control

  • break - Exit loop immediately
  • continue - Skip to next iteration
  • pass - No-op placeholder

Suites (Blocks)

All compound statements use indented suites:

if condition:
    statement1
    statement2
    # blank lines allowed

Empty blocks require explicit pass.

5. Functions

Definition

fn add(a, b):
    return a + b

fn greet(name: str) -> str:
    return "Hello, " + name

fn noop():
    pass

Parameters

Support positional, keyword, default values, *args, **kwargs (Python-compatible syntax):

fn example(a, b=10, *args, **kwargs):
    pass

Return

fn add(a, b):
    return a + b

fn no_return():
    return  # Returns null

Type Annotations

Optional parameter and return type annotations (Python syntax, not enforced at runtime):

fn add(a: int, b: int) -> int:
    return a + b

6. Classes

Definition

class Person:
    fn init(name):
        self.name = name

    fn greet():
        return "Hello, " + self.name

Inheritance

class Employee(Person):
    fn init(name, role):
        super().init(name)
        self.role = role

Implicit Self

Methods in a class receive implicit self as first parameter unless the first explicit parameter is self or cls:

class Example:
    fn method():           # Receives implicit self
        print(self)

    fn explicit(self):     # Explicit self, no implicit added
        print(self)

    fn classmethod(cls):   # cls treated as class method
        print(cls)

Initialization

fn init(...) inside a class transpiles to Python def __init__(self, ...).

Instantiation

let person = Person("Ada")
print(person.greet())

7. Imports and Interoperability

Explicit Python Imports (py import)

Explicitly import Python modules with py import:

py import requests
py import numpy as np
py from pathlib import Path
py from json import dumps, loads

Plain Imports

Python-style imports are also accepted (treated as py import):

import math
from datetime import datetime

Using Imported Objects

Imported Python objects are available directly:

py import math
py from json import dumps

let result = math.sqrt(81)  # 9.0
let json_str = dumps({"value": result}, sort_keys=true)
print(json_str)
Note: Vthon values use Python runtime representations. Imported objects cross the boundary directly with no wrapping.

8. Exceptions

Try/Catch/Finally

try:
    raise ValueError("bad value")
catch ValueError as error:
    print("Caught:", error)
catch:
    print("Caught unknown exception")
finally:
    print("Cleanup")

Rules

  • A try must have at least one catch or finally
  • catch without exception type catches all exceptions
  • as name binds exception to variable (optional)
  • Multiple catch clauses allowed
  • finally is optional, executes after try/catch

Raise

raise ValueError("invalid input")
raise  # Re-raise current exception (in catch block)

9. Execution Model

Pipeline

The implementation must follow this pipeline:

.vth source
    → Lexer (indentation-aware tokens)
    → Parser (recursive-descent, Vthon AST)
    → Transpiler (Vthon AST → Python code)
    → Python AST validation (ast.parse)
    → compile()
    → CPython exec()

Runtime Semantics

  • Vthon code executes in the active CPython runtime
  • Variables are module-scoped (like Python)
  • Functions create new scopes
  • Classes create class namespaces
  • No separate VM or interpreter - direct Python execution

Error Handling

Three error categories with source locations:

TypePhaseDescription
VthonSyntaxErrorLexing/ParsingInvalid syntax, indentation errors
VthonCompileErrorTranspilationConstant reassignment, invalid generated Python
VthonRuntimeErrorExecutionPython exceptions during execution
