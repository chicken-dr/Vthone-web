MVP 0.1.0 API Reference

API Reference

Programmatic API for embedding Vthon in Python applications.

Overview

The Vthon package exposes a minimal public API for parsing, transpiling, and executing Vthon code from Python. All functions are in vthon.runtime.

Python
import vthon.runtime as vthon

# Parse to AST
ast = vthon.parse(source)

# Transpile to Python
python_code = vthon.transpile(source)

# Execute and get namespace
namespace = vthon.execute(source)

# Execute a .vth file
namespace = vthon.run_file("program.vth")

vthon.runtime

parse(source, filename="")

Parse Vthon source code into a Vthon AST (Program node).

ParameterTypeDescription
sourcestrVthon source code
filenamestrSource filename for error reporting (default: "")

Returns: Program - Root AST node with statements list.

Raises: VthonSyntaxError on parse failure.

transpile(source, filename="")

Transpile Vthon source code to Python source code.

ParameterTypeDescription
sourcestrVthon source code
filenamestrSource filename for error reporting

Returns: str - Generated Python source code.

Raises: VthonSyntaxError (parse error), VthonCompileError (transpilation error or invalid generated Python).

execute(source, filename="", namespace=None)

Parse, transpile, and execute Vthon source code.

ParameterTypeDescription
sourcestrVthon source code
filenamestrSource filename
namespacedict | NoneExecution namespace (default: new dict with __name__, __file__)

Returns: dict - Execution namespace with all defined variables/functions/classes.

Raises: VthonSyntaxError, VthonCompileError, VthonRuntimeError (wrapped Python exception).

run_file(path, namespace=None)

Read and execute a .vth file.

ParameterTypeDescription
pathstr | PathPath to .vth file
namespacedict | NoneExecution namespace

Returns: dict - Execution namespace.

Raises: ValueError if file doesn't have .vth extension, plus parsing/transpilation/execution errors.

Error Formatting

All exceptions implement format() for human-readable output:

try:
    vthon.execute(source)
except vthon.errors.VthonError as e:
    print(e.format())
    # Output:
    # file.vth:3:5: error: cannot assign to constant 'PI'
    #   const PI = 3.14
    #   PI = 3.14
    #     ^

Usage Examples

Basic Execution

Python
import vthon.runtime as vthon

source = '''
fn fib(n):
    if n <= 1:
        return n
    return fib(n-1) + fib(n-2)

let result = fib(10)
'''

namespace = vthon.execute(source)
print(namespace["result"])  # 55

Transpile Only

Python
import vthon.runtime as vthon

source = 'let x = 42\nprint(x)'
python_code = vthon.transpile(source)
print(python_code)
# Generated by Vthon 0.1.0
# x = 42
# print(x)

Custom Namespace

Python
import vthon.runtime as vthon

# Pre-populate namespace with Python functions
namespace = {"greet": lambda name: f"Hello, {name}!"}

source = 'print(greet("Vthon"))'
vthon.execute(source, namespace=namespace)
# Hello, Vthon!

Error Handling

Python
import vthon.runtime as vthon
from vthon.errors import VthonSyntaxError, VthonCompileError, VthonRuntimeError

source = "const PI = 3.14\nPI = 3.15"  # const reassignment

try:
    vthon.execute(source)
except VthonCompileError as e:
    print(f"Compile error: {e.message}")
    print(f"At {e.location.filename}:{e.location.line}:{e.location.column}")
except VthonSyntaxError as e:
    print(f"Syntax error: {e.message}")
except VthonRuntimeError as e:
    print(f"Runtime error: {e.message}")

AST Inspection

Python
import vthon.runtime as vthon
from vthon.ast_nodes import FunctionDef, ClassDef

source = '''
fn add(a, b):
    return a + b

class Point:
    fn init(x, y):
        self.x = x
        self.y = y
'''

program = vthon.parse(source)
for stmt in program.statements:
    if isinstance(stmt, FunctionDef):
        print(f"Function: {stmt.name}({stmt.parameters})")
    elif isinstance(stmt, ClassDef):
        print(f"Class: {stmt.name}")
        for method in stmt.body:
            if hasattr(method, 'name'):
                print(f"  Method: {method.name}")
