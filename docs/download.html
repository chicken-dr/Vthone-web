Download & Install

Get Vthon running in under a minute. Requires Python 3.10+.

Quick Install

The fastest way to get started with Vthon.

Via pip (recommended)

Terminal
pip install git+https://github.com/chicken-dr/Vthon.git

This installs the vthon command globally. Requires Python 3.10+ and pip.

Development Install

Terminal
git clone https://github.com/chicken-dr/Vthon.git
cd Vthon
python -m pip install -e .

Installs in editable mode so you can modify the source and test immediately.

Verify Installation

Confirm Vthon is working correctly.

Check Version

Terminal
vthon --version
# Vthon 0.2.0

Run Hello World

Terminal
echo 'let name = "Vthon"
print("Hello from " + name + "!")' > hello.vth
vthon hello.vth
# Hello from Vthon!

Try the REPL

Terminal
vthon repl
# Vthon 0.2.0 REPL (blank line executes a block, Ctrl-D exits)
>>> let x = 42
>>> print(x)
42
>>>

Emit Python

Terminal
vthon --emit-python hello.vth
# Generated by Vthon 0.2.0
name = "Vthon"
print("Hello from " + name + "!")

Requirements

Python Version

Python 3.10 or higher is required.

Terminal
python --version
# Python 3.10.12

Vthon uses modern Python features like match/case (3.10+), pattern matching in the transpiler, and type hints.

Operating Systems

  • Linux - Fully supported (primary development platform)
  • macOS - Fully supported
  • Windows - Supported via WSL or native Python

No platform-specific dependencies. Pure Python implementation.

Dependencies

Zero runtime dependencies. Vthon uses only the Python standard library:

  • ast - Python AST validation
  • tokenize - Lexical analysis
  • argparse - CLI parsing
  • dataclasses - AST nodes
  • enum - Token kinds
  • pathlib - File paths

Uninstall

Terminal
pip uninstall vthon-lang

If installed in editable mode, run pip uninstall vthon-lang from anywhere, then remove the cloned directory.
