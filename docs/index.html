Key Features

Everything you need to write clean, Python-compatible code with Vthon's own syntax

Clean Syntax

Indentation-based with familiar keywords: let, const, fn, class. No braces, no semicolons.

Transpiles to Python

Generates readable Python code that runs on standard CPython. No VM, no runtime overhead, full ecosystem access.

Python Interoperability

Explicit py import statements let you use any Python package directly. requests, numpy, pandas — all work natively.

Complete Toolchain

Lexer, parser, AST, transpiler, CLI, REPL, and diagnostics — all built from scratch in ~870 lines of Python.

Type-Safe Constants

Compile-time protection against reassignment with const. Optional type annotations for clarity.

Modern Exceptions

Full try/catch/finally support with Python-compatible exception handling and raise.

Quick Start

Get up and running in under a minute

1. Install

pip install git+https://github.com/chicken-dr/Vthon.git

Requires Python 3.10+. For development, clone and install in editable mode.

2. Write Code

# hello.vth
let name = "Vthon"
print("Hello from " + name + "!")

Create a .vth file with Vthon syntax. Familiar but cleaner.

3. Run

vthon hello.vth
# Hello from Vthon!

Execute directly, or use vthon repl for interactive development.
