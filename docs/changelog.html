Version 0.1.0

MVP Release 2026-08-05

Initial MVP release of Vthon - a readable indentation-based programming language that transpiles to Python and runs on CPython.

Added

  • Language Core: Variables (let), constants (const), type annotations
  • Literals: Numbers (decimal, binary, octal, hex), strings, booleans (true/false), null, lists, dictionaries
  • Control Flow: if/elif/else, while, for, break/continue/pass
  • Functions: fn definitions, parameters, return statements, optional type annotations
  • Classes: class definitions, inheritance, implicit self, fn init → __init__
  • Exception Handling: try/catch/finally, raise
  • Python Interoperability: py import, py from for explicit Python package imports
  • Comments: Line comments with #

Toolchain

  • Lexer: Indentation-aware (4-space multiples), tab rejection, comment stripping
  • Parser: Recursive-descent, builds source-located Vthon AST
  • AST: Vthon-owned dataclasses with source locations
  • Transpiler: Lowers Vthon to Python, validates with ast.parse(), tracks constants
  • Runtime: Orchestrates parse/transpile/execute, maps errors to Vthon source
  • CLI: vthon file.vth, vthon run, vthon repl, --emit-python, --version
  • REPL: Interactive shell with multi-line block support
  • Diagnostics: Source-located errors for syntax, compile, and runtime phases

Examples Included

  • hello.vth - Hello World
  • variables.vth - Variables and constants
  • functions.vth - Function definitions
  • control_flow.vth - If/elif/else
  • loops.vth - For/while loops
  • classes.vth - Classes with implicit self
  • python_import.vth - Python interoperability

Testing

  • Lexer & parser tests
  • Transpiler & runtime tests
  • CLI end-to-end tests
  • Project layout tests
  • All tests passing (15+ test cases)

Documentation

  • Architecture overview (docs/architecture.md)
  • Grammar reference (docs/grammar.md)
  • Language specification draft (docs/language-spec.md)
  • README with quick start guide

Version 0.2.0

Released 2026-08-07

Major feature release adding pattern matching, decorators, list comprehensions, with statements, and more.

Added

  • Pattern Matching: match/case statement with guards, wildcards, and structural patterns (transpiles to Python match/case)
  • Decorators: @decorator syntax for functions with multiple decorator support
  • List Comprehensions: [expr for target in iterable if condition] syntax
  • With Statements: Context manager support with with expr as target:
  • Enhanced AST: New node types: MatchStmt, MatchClause, ListComprehension, DecoratedFunction, WithStatement, WithItem
  • Lexer: New DECORATOR token type
  • Parser: Decorator handling, list comprehension parsing, with statement parsing, match/case parsing

Changed

  • Version bumped to 0.2.0
  • Updated documentation to reflect v0.2.0 features

Testing

  • All existing tests pass
  • New test cases for pattern matching, decorators, list comprehensions, with statements
