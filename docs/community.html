Contributing

We welcome contributions of all kinds!

Ways to Contribute

  • Code: Fix bugs, implement features, improve performance
  • Documentation: Fix typos, add examples, improve guides
  • Testing: Add test cases, report bugs, verify fixes
  • Examples: Create example programs showcasing features
  • Design: Logo, website improvements, UX feedback
  • Community: Answer questions, mentor newcomers

Development Setup

Terminal
# Clone repository
git clone https://github.com/chicken-dr/Vthon.git
cd Vthon

# Install in development mode
python -m pip install -e .

# Run tests
python -m pytest -q

# Try the REPL
vthon repl

Pull Request Process

  1. Fork the repository
  2. Create a feature branch
  3. Make your changes
  4. Run tests: python -m pytest -q
  5. Ensure code passes linting
  6. Submit PR with clear description
  7. Address review feedback

Code Style

  • Python 3.10+ syntax
  • Type hints encouraged
  • Docstrings for public APIs
  • Follow existing patterns in codebase
  • Keep functions small and focused
  • Tests for new functionality
