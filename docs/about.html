About Vthon

A readable indentation-based programming language that transpiles to Python and runs on CPython.

Philosophy

Own Your Syntax, Keep the Ecosystem

Vthon was created to explore a simple idea: what if you could write code in a cleaner, more readable syntax while still having full access to the entire Python ecosystem?

Many languages that transpile to Python either fork CPython (complex maintenance) or hide the transpilation (debugging difficulty). Vthon takes a different approach:

  • Transparent pipeline: Source → Lexer → Parser → AST → Transpiler → Python → CPython. Every step is visible and debuggable.
  • No hidden magic: Python interoperability is an explicit language feature (py import), not an implementation shortcut.
  • Source-located errors: Every error maps back to your original Vthon code, not generated Python.
  • Stdlib only: Zero dependencies. Runs anywhere Python 3.10+ runs.

Design Goals

  • Readability: Indentation-based, familiar keywords, minimal punctuation
  • Simplicity: ~870 lines of implementation, each component independently understandable
  • Compatibility: Full Python ecosystem access via explicit imports
  • Debuggability: Source locations preserved through entire pipeline
  • Extensibility: Clean separation allows adding features (e.g., pattern matching in PR #1)

What Vthon Is Not

  • Not a Python implementation or fork
  • Not a new runtime or VM
  • Not trying to replace Python
  • Not a toy—real transpiler with real diagnostics
