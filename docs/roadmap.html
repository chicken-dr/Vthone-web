Released in v0.2.0: Pattern Matching & More

Active development tracked in PR #1

Released

Match/Case Pattern Matching

Structural pattern matching following Python 3.10+ semantics has been implemented in v0.2.0.

Implemented in v0.2.0:

  • MatchStmt and MatchClause AST nodes
  • Parser support for match expr: with indented case clauses
  • Guard support: case pattern if condition:
  • Wildcard pattern: case _:
  • Literal, sequence, mapping, and class patterns
  • Transpilation to Python match/case
  • Test cases covering basic, guards, wildcards, list patterns
Example (Planned)
match value:
    case 0:
        print("zero")
    case 1:
        print("one")
    case [x, y]:
        print(f"pair: {x}, {y}")
    case {"type": "error", "msg": msg}:
        print(f"error: {msg}")
    case _ if value > 100:
        print("large")
    case _:
        print("other")

  • File-based module resolution
  • export / from x import y syntax
  • Standard library organization

Type Annotations & Checking

  • Full type hint support in signatures
  • Optional static type checking (mypy integration)
  • Generic type parameters
  • Type inference for let

Async / Await

  • async fn syntax
  • await expressions
  • Async for/with support
  • Integration with Python asyncio

Decorators

  • @decorator syntax for functions/classes
  • Multiple decorators
  • Decorator arguments
  • Class decorators

Generators & Iterators

  • yield in functions
  • Generator expressions
  • yield from support
  • Iterator protocol

Enhanced REPL

  • History persistence
  • Tab completion
  • Syntax highlighting
  • Multi-line editing
  • Inline help
